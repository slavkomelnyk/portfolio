# Image slots

Add your images here, then set the matching `src` prop in the page's `Image` component. Use these sizes so images fit their slots without awkward cropping:

- `profile.jpg` — portrait on the About page; **1200 × 1200 px** (square)
- `camera-embed.jpg` — Camera Embed screenshot; **1600 × 1000 px** (16:10)
- `school-ahead-tv.jpg` — School Ahead TV screenshot; **1600 × 1000 px** (16:10)
- `django-shop.jpg` — Django shop screenshot; **1600 × 1000 px** (16:10)

Project screenshot slots appear on both the home page and Projects page. JPG, PNG, and WebP are suitable formats.
